# Deepak Kharol - Portfolio Website

A modern, responsive portfolio website showcasing my professional experience, skills, and projects as a Senior Software Engineer. The site features an interactive Tetris game, particle effects, and a clean, professional design.

## 🌟 Features

-   **Professional Overview**: Detailed sections on experience, education, and skills.
-   **Interactive Elements**:
    -   Particle effects in hero section.
    -   Typing animation for titles.
    -   Smooth scrolling navigation.
    -   Animated skill cards.
-   **Tetris Game**: A fully functional Tetris game built with vanilla JavaScript.
-   **Project Showcase**: Dynamic project cards with detailed information.
-   **Responsive Design**: Mobile-first layout that works seamlessly on all devices.

## 🛠️ Technologies
-   **HTML5 & CSS3**
-   **JavaScript (ES6+)**
-   **Cloudflare Pages** (Deployment)
